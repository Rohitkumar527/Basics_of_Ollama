# Learning Ollama

A hands-on learning repository exploring Ollama and its integration with Python, REST APIs, LangChain, embeddings, tool calling, and cloud-hosted models.

## Topics Covered

- **Ollama Python Library:** Text generation, streaming, image inputs, model configuration, and model management.
- **REST API:** Interacting with Ollama through HTTP requests and processing streaming responses.
- **LangChain:** Using ChatOllama and OllamaEmbeddings.
- **Tool Calling:** Connecting language models with Python functions.
- **Ollama Cloud:** Exploring cloud-hosted model access.

## Repository Structure

- `01_ollama_python_library.ipynb`
- `02_ollama_rest_api.ipynb`
- `03_ollama_langchain.ipynb`
- `04_ollama_cloud.ipynb`

## Getting Started

1. Install Ollama and set up a compatible model, or configure access to a supported cloud model.
2. Install the required Python packages.
3. Open the relevant notebook and follow the examples.
4. Configure any required cloud authentication before running cloud-model examples.

## Purpose

This repository documents my practical learning journey with Ollama and LLM application development.

*Note: Local model execution requires the appropriate model to be available locally. Cloud-model access depends on the model, account setup, and authentication requirements.*
